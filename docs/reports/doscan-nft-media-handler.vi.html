NFT Media Handler đã tích hợp bằng Google Cloud Storage

Blockscout Mainnet và Testnet giờ tự tải media NFT, tạo thumbnail và lưu vào bucket GCS doscan. Không cần Cloudflare R2 và không cần thêm container riêng.

Testnet: hoạt độngtestnet/nft-media
Public chỉ GETKhông cho list hoặc ghi object
Đã deploy ngày 28/07/2026. PR backend #115 cùng các hotfix #116, #117, #119 và #120 đã merge. Workflow #30331379243 hoàn tất runtime probe thành công cho cả Mainnet và Testnet.

1. Kiến trúc đang chạy

  1. Blockscout đọc URL ảnh hoặc animation từ metadata ERC-721/ERC-1155.
  2. NFT Media Handler chạy inline trong backend, tải và kiểm tra media nguồn.
  3. Backend tạo original cùng thumbnail 60, 250 và 500 px.
  4. Media được upload qua GCS XML API tương thích S3.
  5. Frontend dùng URL public tại https://storage.googleapis.com/doscan.

Handler không phụ thuộc consensus. DOS Chain là Avalanche L1 chạy Subnet-EVM, nên mô hình token và metadata NFT vẫn tương thích EVM như các chain ERC khác.

3. Vì sao GCS dùng được, không cần R2?

Blockscout yêu cầu endpoint S3-compatible chứ không bắt buộc một nhà cung cấp cụ thể. Google Cloud Storage có XML API tương thích công cụ S3, endpoint storage.googleapis.com và HMAC key. Vì vậy DOS có thể tận dụng GCP credit hiện có.

Chi phí GCS gồm dung lượng lưu, số thao tác và băng thông ra ngoài. Với lưu lượng NFT hiện tại, chi phí dự kiến nhỏ và được trừ vào credit, nhưng vẫn cần theo dõi object count và egress khi marketplace hoạt động trở lại.

4. Secret và policy bucket

  • HMAC nằm trong Google Secret Manager: doscan-nft-media-hmac.
  • Workflow đọc secret qua Workload Identity Federation, tạo file tạm mode 0600, merge vào secret env trên VM rồi xóa file tạm.
  • Repo không chứa access ID hoặc secret HMAC.
  • Service account ghi object: doscan-nft-media@dos--ai.iam.gserviceaccount.com.
  • Public dùng custom role doscanPublicObjectReader, chỉ có storage.objects.get.
Probe ẩn danh ngày 28/07/2026: GET thumbnail đã biết trả HTTP 200; XML bucket list trả HTTP 403; JSON bucket list trả HTTP 401.
Lưu ý rotate key: Mainnet và Testnet đang dùng chung một HMAC service account. Phải deploy và kiểm tra cả hai môi trường trước khi vô hiệu hóa key cũ.
