1. Mục tiêu và phạm vi

Trong phạm vi

  • Tự động verify hai contract Account Abstraction v0.8 trên Testnet 3939.
  • Kiểm tra full verification và exact compiler metadata.
  • Retry có giới hạn khi Blockscout xử lý chậm hoặc kết nối tạm lỗi.
  • Regression test cho logic submit, poll và fail-closed.

Ngoài phạm vi

  • Không deploy lại contract.
  • Không sửa contract hoặc repo eth-infinitism/account-abstraction.
  • Không sửa lõi Blockscout Backend, Frontend hoặc smart-contract-verifier.
  • Không áp dụng cho Mainnet trong thay đổi này.

Ranh giới repo

  • Chỉ sửa workflow, script và test trong DOScan.
  • Upstream source chỉ được tải read-only tại commit đã pin.
  • Không commit private key, token hoặc credential.

3. Luồng thực thi

fetch exact commit -> install pinned toolchain -> compile -> extract standard input -> package immutable artifacts -> deploy stack -> verify through local Caddy -> poll exact metadata -> finish
  1. GitHub Actions tải đúng upstream commit và từ chối nếu Git không resolve về SHA đã pin.
  2. Toàn bộ bước cài dependency và compile upstream chạy trước khi workflow cấp GCP credential.
  3. Workflow cài Yarn v1 đã pin, compile bằng Hardhat và lấy standard input trực tiếp từ build-info.
  4. Chỉ hai standard input cần thiết cùng script verify được đưa vào archive deployment Testnet.
  5. Remote deployment hoàn tất toàn bộ runtime health gate hiện có trước khi chạy source verification.
  6. Script gọi API v2 chuẩn của Blockscout qua Caddy nội bộ trên VM để tránh cache CDN và vẫn đi qua route production thật.
  7. Nếu metadata đã exact, script không submit lại. Nếu chưa verified, script submit standard input rồi poll bounded.
  8. Sau tối đa 5 phút, workflow chỉ thành công khi cả hai contract đạt toàn bộ acceptance gate.

4. Acceptance gate

Mỗi contract phải đồng thời thỏa các điều kiện sau:

  • is_verified=true và is_fully_verified=true.
  • Không phải partial verification.
  • Tên contract và source path khớp chính xác.
  • Compiler khớp v0.8.28+commit.7893614a.
  • EVM version là cancun.
  • Optimizer bật với đúng 1,000,000 runs.
  • License khớp chính xác: EntryPoint là gnu_gpl_v3, Factory là mit.
  • Factory có constructor arguments trỏ đúng EntryPoint v0.8.
  • API trả JSON hợp lệ, không có trạng thái lỗi hoặc metadata mâu thuẫn.
Fail-closed: một contract sai metadata khiến workflow fail. Script không chấp nhận trạng thái gần đúng, partial match hoặc response thiếu field bắt buộc.

5. Retry và an toàn rollback

  • Mỗi request có connect timeout và transfer timeout hữu hạn.
  • Poll có deadline tổng khoảng 5 phút, đủ cho thời gian xử lý đã quan sát khoảng 102 giây của SimpleAccountFactory.
  • Các lỗi kết nối tạm thời và trạng thái pending được retry. Metadata sai sau khi verified bị từ chối ngay.
  • Source verification chạy sau khi workflow đặt DEPLOYMENT_STARTED=0.
  • Nếu verification fail, workflow vẫn trả trạng thái fail nhưng không kích hoạt destructive database restore.
  • Rerun là idempotent: contract đã exact được bỏ qua, contract chưa exact được submit hoặc poll lại. Response Already verified chỉ được chấp nhận sau khi GET xác nhận exact metadata.
